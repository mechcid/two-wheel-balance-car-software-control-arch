## 力矩贡献分解

对每个状态分量计算 `-K[i][j]*error[j]`，俯仰角速度项再乘实际系数 0.5。下表为左轮各项的 RMS，右轮幅值近似相同，航向项符号相反。RMS 表示本窗口的典型幅值，不是各项能量占比，也不能直接相加。

| 输入分量 | 力矩贡献 RMS（Nm） |
|---|---:|
| 纵向位置 | 0.0256 |
| 航向角 | 0.00294 |
| 俯仰角 | 0.0295 |
| 前进速度 | 0.0243 |
| **航向角速度** | **0.1012** |
| 俯仰角速度（已乘 0.5） | 0.0531 |

将两轮请求力矩拆成共同分量 `(L+R)/2` 和差动分量 `(L-R)/2`：共同分量 RMS=0.0675 Nm，差动分量 RMS=0.1015 Nm。差动输出比共同输出更大。

例如本窗口约 0.175 秒时，航向角速度为 1.191 rad/s，仅这一项就分别要求左右轮约 +0.168/-0.168 Nm；俯仰角项仅约 +0.0175 Nm。这里很大一部分电机动作是在响应航向角速度，而非单纯纠正前后倾斜。

这说明航向角速度反馈是差动命令的重要驱动项，但闭环数据中输入与输出相互作用，不能仅凭贡献大断定它是唯一根因或符号错误。

## 值得继续核实的相位差

按文档轮半径 0.0325 m、轮距 0.185 m，以及无滑动差速运动关系，用两轮转速计算航向角速度代理值。它与 IMU 给出的航向角速度在同一时间点的相关系数约 0.28；用较早的轮速与约 20–25 ms 后的 IMU 航向角速度比较，相关系数提高到约 0.95–0.96。

该结果提示两种测量之间存在明显相位差，是排查传感器滤波、安装/车体弹性、轮胎接地与模型动态差异的线索。它不是对“陀螺仪延迟 25 ms”的测量：短窗口、周期波形、打滑、车体运动和时间口径差异都可能影响相关性。不应直接按这个数做时移补偿。

## 建议下一次只改变一个变量

优先做航向角速度反馈的对照试验：在独立 LqrTuning 中增加 yaw_rate_scale，基准为 1.0，对照为 0.5，仅作用于 psi_dot 项。保留原始 K、航向角项、俯仰角速度系数 0.5、占空比上限和其他保护。这里的 0.5 是用于验证假设的试验值，不是计算出的最终最优增益。

在相同着地和扶护条件下比较：航向角速度峰值、差动力矩 RMS、限幅帧比例和俯仰波动范围。如果差动摆动及俯仰波动同步下降，支持航向环动态对当前不稳定有重要影响；若航向摆动下降而俯仰仍明显振荡，应继续独立排查俯仰环。若效果变差则恢复基准，继续查相位差。

不建议此时同时修改多个 K 分量，或通过提高占空比上限来掩盖限幅。上述是后续试验建议，本次没有修改控制固件、烧录或启动电机。
