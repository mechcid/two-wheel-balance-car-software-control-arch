# 两轮平衡车 LQR 控制模块接入说明

本文是提供给控制模块开发者 / agent 的接口交接文档，不要求重新推导拉格朗日方程。适用分支：`dissymmetry_motor`。数值来源提交：`12ef6660d30d5b224a2e3e83848f02f9f9d0d813`，从该版本的两个 `design()` 函数重新计算。

配套文件：[LQR接入参数 JSON](2026-10-17_LQR接入参数.json)。JSON 保存完整精度的 A、B、K、Q、R、参考状态参数和车辆参数，程序优先读取 JSON，避免手抄数值。A/B 描述状态变化率，K 则直接把当前误差映射为力矩；反馈时不需要先算 A E+B u。

## 0. 接入前必须知道：这两组 K 是连续时间设计

**本文两组 K 可用作理论基准和连续模型仿真，不能直接复制到当前 200 Hz 节点后上车。**

以理想线性对象、精确状态测量、无额外延迟、每周期内保持力矩输出为条件，计算 `Ad-Bd@K` 的谱半径（小于1才是离散渐近稳定）：

| 控制周期 | 频率 | 直立谱半径 | 圆周谱半径 | 直接使用本文连续 K |
|---|---:|---:|---:|---|
| 0.5 ms | 2000 Hz | 0.999654602 | 0.999772662 | 理想线性检查通过，不代表实机验证 |
| 1 ms | 1000 Hz | 0.999309325 | 0.999545377 | 理想线性检查通过，不代表实机验证 |
| 2 ms | 500 Hz | 2.995707549 | 2.996425237 | 失稳 |
| 5 ms | 200 Hz | 9.060060945 | 9.064570372 | 失稳 |
| 10 ms | 100 Hz | 19.372294883 | 19.390500969 | 失稳 |

原因是原 Q/R 在这套实车参数下产生了很快的闭环模态，最快连续闭环极点约为 -1989 s^-1。此前数学仿真是连续反馈，输出数据间隔 0.02 s 不等于控制周期。

接入 agent 应先确定真实控制周期 Ts、内环类型和延迟，再对本文对应的 A/B 离散化、设计离散 LQR，并重新校验。不要简单给 K 乘以 Ts 或改变单位来补偿。两套控制器的状态定义、误差计算、输入输出约定可以直接按本文实现；数值增益需要匹配实际执行方式。

当前 ROS `balance_yaw` 还是历史六状态控制器，默认频率200 Hz，不能把这里的2×7增益直接填入其2×6接口。历史 ROS 物理参数也仍是示例值。

## 1. 两种模式速览

| 模式 | 目标 | 反馈向量 | K 尺寸 | 输出 |
|---|---|---|---|---|
| 直立平衡 | 固定位置、固定航向、直立、速度为零 | 六维局部状态误差 | 2×6 | 左右轮轴力矩，N·m |
| 匀速圆周 | v_ref=+0.1 m/s，omega_ref=+0.4 rad/s | 七维参考航向误差 | 2×7 | 左右轮轴力矩，N·m |

本圆周参考的半径为0.25 m，从上方观察为逆时针 / 左转，一圈约15.708 s。该 K 针对这一对参考速度；改变速度、曲率、方向或车辆参数，需重新生成匹配的参考解和增益。不要把圆周增益用于零速原地平衡。

共同控制律：

$$\tau_{raw}=\tau_{ref}-K E,\qquad \tau=[\tau_L,\tau_R]^T.$$

- 误差统一采用“实际值减参考值”。
- 负反馈的负号不能再加到 K 内部后又在外面重复加。
- K 第一行输出左轮力矩，第二行输出右轮力矩。
- K 输入为状态误差，不是状态导数，也不是电机编码器角度数组。
- 矩阵乘法后不乘控制周期。

## 2. 坐标、单位和传感器约定

### 2.1 坐标轴与符号

- N：固定惯性坐标系。水平 x/y，z 向上。
- C：原点是左右轮轴中点，x 为当前水平前向，y 向左，z 向上。
- B：固定在车体上，车体相对 C 绕 +y 轴俯仰。
- 左轮位于 C.y=+d/2，右轮位于 C.y=-d/2。
- psi：航向角，绕 +z 的右手正方向，从上方看逆时针为正。
- theta：车体俯仰角。theta=0 为模型直立；正 theta 表示车体上方轴 B.z 朝前方 +C.x 倾斜。
- v：轮轴中点沿小车当前水平前向的速度，前进为正。
- omega=psi_dot：航向角变化率；p=theta_dot：俯仰角变化率。
- tau_L、tau_R：电机施加给车轮的轮轴输出力矩，正方向均按 +C.y 定义；理想滚动下，两轮正角速度对应前进。

位置用 m，角度用 rad，线速度用 m/s，角速度用 rad/s，力矩用 N·m。不允许把角度或角速度的“度”直接送入 K。

### 2.2 需要估计的统一状态

控制接口输入建议采用：

```text
state = [x, y, psi, theta, vx_world, vy_world, omega, p]
```

x、y、vx_world、vy_world 都是**轮轴中点**的位置与速度，不能未经换算就使用车体质心或偏置 IMU 位置。若里程计速度是在子坐标系表达，先转换到 N 系；如果参考点偏离轮轴中点，还需处理刚体速度的杠杆臂项。

角速度分量与欧拉角速率也不能混用。IMU 先对齐到车体 B 系，若读数为 gx、gy、gz，姿态采用本项目的 ZYX 约定，roll 为 phi，则：

$$p=\cos\phi\,g_y-\sin\phi\,g_z,$$
$$\omega=\frac{\sin\phi\,g_y+\cos\phi\,g_z}{\cos\theta}.$$

理想无翻滚时 p=gy、omega=gz/cos(theta)。直立小角度时才近似 omega≈gz。需要校准安装旋转、俯仰零点、陀螺仪偏置和时间戳。

若使用轮编码器估计速度，必须明确它测的是轮相对车体的转角 alpha，还是轮相对 C 的转角 theta_w。按项目正方向、且编码器已换算到轮轴后：

$$\dot\theta_{wL}=\dot\alpha_L+p,\quad
\dot\theta_{wR}=\dot\alpha_R+p,$$
$$v=\frac r2(\dot\alpha_L+\dot\alpha_R+2p),\quad
\omega=\frac r d(\dot\alpha_R-\dot\alpha_L).$$

若输入已经是轮相对 C 的角速度，则不再加 p。编码器、电机左右安装镜像和减速比必须由适配层统一；这些公式不意味着仅凭编码器即可无漂移获得世界位置。

## 3. 模式一：固定位置直立平衡

### 3.1 工作点和状态空间

原推导的状态为 `[delta_x, delta_psi, delta_theta, delta_xdot, delta_psidot, delta_thetadot]`，增益在名义航向 psi0=0、静止直立、零输入处计算。

为了在任意初始航向使用同一组增益，建立一个**固定的局部参考系**：其 x 轴沿目标固定航向 psi_hold。利用水平旋转不变性，这与把名义航向设为0一致。不要一边改变该坐标系，一边沿用本节定常模型。

固定目标为 `(x_hold,y_hold,psi_hold)`，误差向量定义为：

$$E_s=[e_x,e_\psi,e_\theta,e_{\dot x},e_\omega,e_p]^T.$$

| 下标 | 元素 | 物理含义与计算 | 单位 |
|---:|---|---|---|
| 0 | e_x | cos(psi_hold)(x-x_hold)+sin(psi_hold)(y-y_hold)，沿固定目标前向的位置误差 | m |
| 1 | e_psi | wrap(psi-psi_hold)，航向误差 | rad |
| 2 | e_theta | theta，直立俯仰误差 | rad |
| 3 | e_xdot | cos(psi_hold)vx_world+sin(psi_hold)vy_world，沿固定目标前向的速度 | m/s |
| 4 | e_omega | omega，参考值为0 | rad/s |
| 5 | e_p | p，参考值为0 | rad/s |

wrap 表示把角差归一到 [-pi,pi)。模型只适用于参考附近的小误差；wrap 不是让该控制器能处理任意大航向偏差。

e_x 是固定方向的位置投影，不是沿当前车头方向累计的里程 s。此六状态控制器没有横向位置误差项，不承诺恢复横向位置。

局部状态方程：

$$\dot E_s=A_sE_s+B_s\delta\tau.$$

## 4. 模式二：以指定速度做圆周运动

### 4.1 实际世界状态与参考轨迹

实际世界状态为：

$$Z=[x,y,\psi,\theta,v,\omega,p]^T,$$

其中

$$v=\cos\psi\,v_x^N+\sin\psi\,v_y^N.$$

这里 v 沿**实际当前航向**投影，不是世界 x 速度，也不是按参考航向投影。

本文增益对应：

```text
v_ref     = 0.1 m/s
omega_ref = 0.4 rad/s
theta_ref = -2.5142967573183277e-07 rad
p_ref     = 0 rad/s
tau_ref   = [8.352958197628564e-11, -3.8411413609532806e-11] N·m
```

theta_ref 与 tau_ref 是精确动力学解出的常值。虽然很小，接入时按给定数值保留即可，不需要自行重新猜测平衡角。

取圆周运动开始时刻为 t_start，elapsed=t-t_start，并固定轨迹起点 `(x0,y0,psi0)`：

$$\psi_r=\psi_0+\omega_{ref}\,elapsed,$$
$$x_r=x_0+\frac{v_{ref}}{\omega_{ref}}(\sin\psi_r-\sin\psi_0),$$
$$y_r=y_0+\frac{v_{ref}}{\omega_{ref}}(\cos\psi_0-\cos\psi_r).$$

$$Z_r=[x_r,y_r,\psi_r,\theta_r,v_{ref},\omega_{ref},0]^T.$$

轨迹时间使用单调、连续的时钟；起点和开始时间只在模式初始化时记录，不能每个控制周期重置，否则位置误差会被人为抹掉。psi_r 可以连续增长，三角函数直接使用它，航向误差再做 wrap。

### 4.2 K 的输入是参考航向误差，不是直接使用世界状态差

先求 dx=x-x_r、dy=y-y_r，再构造：

$$E_c=\begin{bmatrix}
\cos\psi_r\,dx+\sin\psi_r\,dy\\
-\sin\psi_r\,dx+\cos\psi_r\,dy\\
\operatorname{wrap}(\psi-\psi_r)\\
\theta-\theta_r\\
v-v_{ref}\\
\omega-\omega_{ref}\\
p
\end{bmatrix}.$$

| 下标 | 元素 | 物理含义 | 单位 |
|---:|---|---|---|
| 0 | e_parallel | 相对参考位置，沿参考车头前向的位置误差；正值为超前 | m |
| 1 | e_left | 相对参考位置，沿参考车头左侧的位置误差；正值为偏左 | m |
| 2 | e_psi | 实际航向减参考航向 | rad |
| 3 | e_theta | 实际俯仰减参考俯仰 | rad |
| 4 | e_v | 实际前向速度减参考前向速度 | m/s |
| 5 | e_omega | 实际偏航角速度减参考值 | rad/s |
| 6 | e_p | 实际俯仰角速度减参考值0 | rad/s |

位置误差的旋转用**参考航向 psi_r**。不要用实际航向 psi 替换，也不要旋转两次。

## 5. 可复制的状态组装与反馈代码

下面代码展示接口数学含义，加载的是连续设计 K。若用于实际周期控制，先按第7节完成离散设计，再替换对应 K；状态组装方法不变。

```python
# BEGIN_HANDOFF_EXAMPLE
import json
from pathlib import Path
import numpy as np

PARAMETER_FILE = Path("doc/2026-10-17_LQR接入参数.json")
config = json.loads(PARAMETER_FILE.read_text(encoding="utf-8"))
K_S = np.asarray(config["upright"]["K"], dtype=float)
K_C = np.asarray(config["circle"]["K"], dtype=float)
CIRCLE = config["circle"]

def wrap(angle):
    return np.arctan2(np.sin(angle), np.cos(angle))

def upright_error(state, hold):
    # state: [x,y,psi,theta,vx_world,vy_world,omega,p]
    # hold: 固定的 [x_hold,y_hold,psi_hold]
    x,y,psi,theta,vx,vy,omega,p = state
    xh,yh,psih = hold
    cs,sn = np.cos(psih),np.sin(psih)
    return np.array([
        cs*(x-xh)+sn*(y-yh), wrap(psi-psih), theta,
        cs*vx+sn*vy, omega, p
    ], dtype=float)

def circle_reference(elapsed, start):
    # start: 固定的 [x0,y0,psi0]；elapsed: 距模式开始的秒数
    x0,y0,psi0 = start
    v0,w0 = CIRCLE["v_ref"],CIRCLE["omega_ref"]
    psir = psi0+w0*elapsed
    return np.array([
        x0+v0/w0*(np.sin(psir)-np.sin(psi0)),
        y0+v0/w0*(np.cos(psi0)-np.cos(psir)),
        psir,CIRCLE["theta_ref"],v0,w0,0.
    ])

def circle_error(state, ref):
    x,y,psi,theta,vx,vy,omega,p = state
    xr,yr,psir,thetar,vr,wr,pr = ref
    cs,sn = np.cos(psir),np.sin(psir)
    v = np.cos(psi)*vx+np.sin(psi)*vy
    return np.array([
        cs*(x-xr)+sn*(y-yr), -sn*(x-xr)+cs*(y-yr),
        wrap(psi-psir), theta-thetar, v-vr, omega-wr, p-pr
    ])

def upright_torque(state, hold):
    error = upright_error(state,hold)
    if not np.isfinite(error).all():
        raise ValueError("invalid state")
    return -K_S @ error

def circle_torque(state, elapsed, start):
    error = circle_error(state,circle_reference(elapsed,start))
    if not np.isfinite(error).all():
        raise ValueError("invalid state")
    return np.asarray(CIRCLE["tau_ref"]) - K_C @ error
# END_HANDOFF_EXAMPLE
```

这里只实现状态误差与反馈映射，不包含状态估计、模式管理、失联保护或电机驱动。异常必须由上层捕获并进入明确的安全输出状态，不能继续沿用上一帧力矩。

## 6. 从左右轮力矩到实际电机命令

K 输出是**左右轮轴力矩**，不是 PWM、电压、转速，也不是电机轴端力矩。

- 在关节 effort 接口中，可以按 `[左轮,右轮]` 输出 N·m，但应先确认关节轴方向和顺序。
- 如果电机驱动提供电流环，按已标定的力矩常数、减速比和效率换算，例如 `i = tau_wheel / (eta * gear_ratio * Kt)`，再应用左右通道的实际方向映射。
- 若只有电压/PWM接口，需要建模或标定电流—力矩响应，或增加合适的电流内环。不能把 N·m 数值直接当作 PWM 占空比。
- 限幅必须来自实际驱动、电机、电源和传动能力。数学仿真中的 ±1 N·m 是测试设置，不是实测电机能力。
- 限幅应作用在包含前馈后的总请求力矩上；分别记录请求值和实际施加值。原 LQR 没有积分器，不要为了消除静差直接叠加未设计的积分项。

项目力矩符号的物理核对：正的 tau_L、tau_R 同时作用时，前向广义驱动为 `(tau_L+tau_R)/r`；偏航广义驱动为 `d*(tau_R-tau_L)/(2r)`；车体受到的俯仰反作用力矩为 `-(tau_L+tau_R)`。这些是广义驱动力的符号，不代表耦合系统每个瞬间的实际加速度都能独立按其判断。

## 7. 交给接入 agent 的离散设计要求

1. 确定目标平台的真实 Ts、传感器更新率、执行器内环和延迟。不要因为现有节点写了200 Hz就假设这组连续 K 已适配它。
2. 直立使用 JSON 中 upright.A/B；圆周使用 circle.A/B，也就是 A_e/B_e。
3. 在轮轴力矩零阶保持假设下，用矩阵指数计算 Ad、Bd：

   `exp([[A,B],[0,0]] * Ts) = [[Ad,Bd],[0,I]]`。

4. 根据离散性能指标选择 Qd、Rd，再用离散 Riccati 方程求 Kd。不能把连续 CARE 当作离散 DARE。若要求精确保留连续时间积分代价，应进行代价离散化，包括可能出现的状态—输入交叉项；简单 Qd=Q*Ts、Rd=R*Ts 只是近似设计选择。
5. 验证 `max(abs(eig(Ad-Bd@Kd))) < 1`，并进一步加入采样保持、测量滤波、计算与驱动延迟、饱和，运行非线性闭环。
6. 保存新的 Ts、状态/输入顺序、Qd/Rd、Kd 以及对应物理参数。使用本文状态组装函数，把连续 K 换为经验证的 Kd。

本文的连续设计权重为：

```text
直立 Q = diag([10, 5, 400, 5, 2, 40])
圆周 Q = diag([10, 10, 5, 400, 5, 2, 40])
两者 R = diag([10, 10])
```

仅提高名义频率不能代替延迟、噪声和执行器验证；即使1 ms的理想线性检查通过，也不是实机频率推荐。

## 8. 模式启动与切换

建议先接入并验证直立模式，再加入圆周轨迹跟踪。

- 直立启动：确定固定目标位置和航向；状态估计已初始化，俯仰零点和左右电机符号已验证，状态处于局部范围。
- 圆周启动：本文参考在 t=0 就有0.1 m/s前进速度和0.4 rad/s偏航速度。已有仿真从该运动参考附近起步，**没有验证从静止直接硬切入该参考**。
- 如果需要从直立静止过渡到圆周运动，应设计平滑速度过渡及其可行参考、前馈和控制器策略，再做仿真。不要随意给 v_ref、omega_ref 加斜坡，却继续声称它是本文的恒定速度参考解。
- 模式切换保持同一位置坐标系和一致时间基准；明确记录切换时刻、固定参考起点和增益版本，避免参考位置跳变。

## 9. 最低接口验收项目

- K 的形状为2×6或2×7，输入误差长度正确；左右输出顺序固定。
- 全部输入使用 SI 单位，并明确速度所属坐标系与参考点。
- 直立零误差输出 `[0,0]`；圆周零误差输出 tau_ref。
- 0.03 rad俯仰误差测试应与本文输出一致，验证负号、列顺序和左右顺序。
- 航向跨 ±pi 时误差保持连续的小量，不突然变成约2pi。
- 圆周位置误差按参考航向旋转；例如参考航向 pi/2 时，世界 +y 是前向，世界 -x 是左侧。
- 非零起始位置和航向下，圆周参考 t=0 正确返回指定起点。
- 采样闭环、状态超时、非有限输入、倾角越界、力矩限幅和急停均有验证；阈值由实际系统确定，不从数学仿真结果臆造。
- 日志至少包含时间、模式、实际状态、参考状态、实际反馈误差、请求力矩、限幅后命令、数据年龄及所用 Ts/K 版本。
