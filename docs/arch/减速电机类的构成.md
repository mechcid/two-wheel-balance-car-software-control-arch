# 减速电机类的构成

减速电机类负责单个电机的驱动输出和编码器反馈。它提供本采样区间的运动增量，不负责累计小车位置或路程；这些结果由里程计计算和维护。

## 1. 配置参数

配置包含方向控制引脚、PWM 输出引脚、绑定的编码器、正反转与停止真值表，以及计数换算比例、轮半径、方向极性和占空比限制。

配置描述硬件连接和换算规则，与运行过程中不断变化的工作状态分开保存。

## 2. 工作状态与编码器反馈

| 内容 | 当前存储位置 | 用途 |
| --- | --- | --- |
| 当前计数、上次计数与计数差值 | 绑定的 `Encoder` 实例 | 获取本区间编码器变化，处理计数器回绕 |
| 有符号累计计数 | `MotorState.total_counts` | 用于计算及调试参考，不代表车体路程 |
| 本采样区间等效轮缘位移 | `MotorState.delta_displacement_m` | 供里程计消费的增量，单位为米 |
| 转速与等效轮缘速度 | `rpm`、`velocity_mps` | 描述本次采样区间的运动反馈 |
| 实际施加的逻辑占空比 | `applied_duty` | 记录驱动输出 |
| 有效性 | `total_counts_valid`、`delta_valid`、`feedback_valid` | 分别描述累计计数完整性、单段位移及速度反馈是否可信 |

累计计数从最近一次成功 `begin()` 开始。正常停止和重建测速基准不清零；计数丢失后保留已知值，恢复后继续累计可观测增量，但 `total_counts_valid` 不自动恢复为真。再次成功执行 `begin()` 才建立新计数原点并恢复该标志。

累计计数不完整，不意味着之后每一段反馈都无效：恢复基准后，新的区间位移和速度可以重新有效。模块不再保存或计算累计轮行程；车体位置、累计位移和路程由里程计按各自定义维护。

## 3. 反馈更新

`updateFeedback(dt_s)` 接收外部提供的实际采样间隔，读取编码器、更新累计计数、计算本区间位移和速度，并维护有效性标志。电机类本身不决定调用频率。

`rebaseFeedback()` 用于重建测速基准；基准仍可信时，先补计尚未读取的增量。无法恢复的历史计数不通过推算补齐。

## 4. 输出控制与访问边界

外部通过 `setDuty()` 设置占空比，由电机类完成限幅、方向处理和 PWM 输出；通过 `stop()` 撤销驱动输出。撤销输出并不意味着电机机械转速立即归零。

配置和工作状态由类内部维护，外部通过 `state()` 获取只读状态，不直接修改内部反馈记录。`MotorApp` 在更上层组织双轮采样，提供时间戳、采样区间、发布序号和整帧有效性。
