## 当前项目接线

| 模块引脚 | 本工程连接或用途 |
|---|---|
| VCC | 保持用户已接好的供电；商家说明 3.3V/5V 可用，原理图画的是经 LDO 的 5V 输入 |
| GND | 与 STM32、HC-05 共地 |
| SCL | PB10 / I2C2_SCL，100 kHz |
| SDA | PB11 / I2C2_SDA |
| AD0 | 低电平地址 0x68，高电平地址 0x69；本次探测为 0x68 |
| XDA、XCL | 辅助 I²C 接口，用于外接传感器；本工程不用 |
| INT | 数据就绪等可配置中断输出；本工程未配置或依赖此引脚 |

原理图 R4、R5 为 4.7 kΩ，上拉到模块的 3.3V。AD0 下拉在原理图为 4.7 kΩ，商家文字写 10 kΩ，存在冲突；不能把文字值当成实物测量结果。

商家关于外加磁传感器能解决静止数值波动的说法不准确；磁传感器可为航向提供参考，不能消除所有传感器噪声。INT 也需要寄存器配置后使用，不是本工程自动产生控制周期的来源。

USART2：PA2（TX）→ HC-05 RX，PA3（RX）← HC-05 TX，9600、8N1。蓝牙地址和 UART 波特率是两层配置：PC 直连 RFCOMM 不会自动设置 HC-05 的 UART 波特率。
